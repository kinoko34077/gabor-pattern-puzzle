# ガボールパターンパズル

画面の大きさと向きに合わせて模様を並べる、ブラウザだけで遊べるマッチ3パズルです。スマートフォン・PCの両方に対応し、PWAとしてインストールしてオフラインでも利用できます。

## 遊び方

模様を上下左右にドラッグし、同じ種類を3つ以上並べると消えます。消去・連鎖でスコアと残り時間が増加します。

- 「表示」：ガボール／白黒／立体視を切り替えます。表示切替時は新しいゲームが始まります。
- 「配色」：押すたびに「従来の単色→七彩・ソフト→夕映え→夜光→好みの単色→従来の単色」とデザインを順送りで変更します。
- 「＋」「－」：盤面を拡大・縮小します。模様の表示サイズと個数のバランスを調整できます。
- 「ヒント」：交換候補を示します。残り時間を消費します。
- 「設定」：設定ボタンのそばの小型ポップアップから、ゲーム時間、デザイン、背景・模様の色、密度、動きの速さを変更します。背景はぼかさず、配色の変化を確認できます。
- 「一時停止」：時間・得点・盤面処理を止め、同じ設定から「再開」できます。設定を表示している間も時間は止まります。
- 「ゲームの終了」：現在のゲームを中断し、初期の待機状態に戻します。
- キーボード：矢印で選択位置を移動、Shift＋矢印で交換、Hでヒント、Sで設定を開きます。

ゲーム未開始でも模様の渦巻き状の回転と外周のぼかしは変化します。明示的な一時停止中・設定中にも模様の変化は継続し、ゲームの時間・得点と交換・消去の進行は停止します。配色切替の通知は画面端に短く表示します。

## レスポンシブ表示

横画面では操作欄を**右端**へ縦配置し、上から「設定・表示・配色・＋・－・ヒント・得点」と並べます。縦画面では、横画面を時計回り90°回した位置関係に従い、操作欄を**画面下端**へ横配置します。このとき左から「得点・ヒント・－・＋・配色・表示・設定」の順になり、この90°は操作欄の位置関係の変更を示し、模様・アイコン・得点・設定画面・終了画面自体は横倒しにせず画面に対して正立表示します。残りの表示領域全体が盤面になります。盤面の行・列数だけでなく、一つひとつの模様の大きさもウィンドウ面積に応じて変更します。表示方向が変化しても進行中のスコア・残り時間を保持し、重なる領域のセルを維持します。交換・消去中の回転でも描画座標を直ちに更新し、行列数の再編成だけを安全なタイミングまで遅らせます。タブレットを含めて端末の上下左右の画面安全領域を除外し、ゲームと操作欄を可視領域内に収めます。

## 色の設計

異なる種類の模様に異なる色を割り当てるデザインを用意しました。カテゴリーの区別には[ColorBrewerの定性的配色](https://colorbrewer2.org/learnmore/schemes_full.html)、補色・類似色の調和には[Adobeのカラーホイール資料](https://www.adobe.com/uk/creativecloud/design/discover/color-wheel.html)を参考にしています。文字や操作要素の見やすさには[WCAG 2.2](https://www.w3.org/TR/WCAG22/)のコントラスト原則を参照しています。

デザインは「従来の単色」「七彩・ソフト」「夕映え」「夜光」「好みの単色」。操作欄の配色ボタンから各デザインを直接循環でき、変更後の名前が画面端に控えめに短時間表示されます。設定画面では個別の色を調整できます。

## 開発・検証

```bash
npm ci
npm run check
```

TypeScript・Canvas 2Dとブラウザ標準APIのみを使用します。公開配信はGitHub Pagesで行い、Service Workerによって配信コミット単位のキャッシュを更新します。

## 注意

本アプリは視覚模様を表示するゲームです。視力・疾患への治療効果を保証するものではありません。
